# Cedar Point OS

**Cedar Point OS** هو نظام التشغيل الذكي لوكالة **Cedar Point Media** — الدماغ الرقمي الذي يفكر مع الوكالة، يتعلّم من خبرتها، ويحفظ معرفتها، بينما يبقى القرار والتحكم النهائي دائمًا بيد الإنسان.

هذا المستودع هو المرجع الرسمي للمشروع: **Cedar Point OS Master Project Bible**. أي فريق أو أي نظام ذكاء اصطناعي يعمل على المشروع يرجع لهذه الوثيقة أولًا حتى يبقى العمل متسقًا مع الرؤية الأساسية.

## المبادئ الحاكمة للمستودع

- كل معلومة تدخل النظام يجب أن تولّد قيمة لبقية الموديولات — لا جزر معزولة.
- كل أتمتة يجب أن تكون شفافة وقابلة للشرح.
- أي إجراء ذو أثر يتطلب موافقة صريحة من المالك قبل التنفيذ.
- البنية معيارية وقابلة للتوسّع دون الحاجة لإعادة بناء الأساس.
